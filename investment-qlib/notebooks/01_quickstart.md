# 快速上手（说明）

下面给出最小步骤帮助你在本项目里快速运行 qlib。

1. 安装依赖

```bash
pip install -r requirements.txt
```

2. 准备数据

- 推荐使用 qlib 的样例数据或按照官方文档下载并准备数据，设置 `provider_uri` 指向数据目录。

3. 运行示例

```bash
python examples/quickstart.py
```
